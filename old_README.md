# AI-Pharmacist-Hackathon
Agentic AI system for autonomous digital pharmacy
This project is an AI-driven pharmacist that supports natural voice/text ordering, enforces medicine and prescription safety, predicts individual refill needs, and autonomously drives backend operations with minimal human intervention.
## Core Features
- **Conversational Ordering:** Supports natural text and voice conversations to extract medicine names, dosages, and quantities.
- **Safety & Policy Enforcement:** Automatically checks prescriptions and stock levels before processing orders.
- **Predictive Intelligence:** Proactively predicts when patients need refills using historical data.
- **Real-world Action:** Triggers backend actions such as inventory updates, webhooks, and notifications.
- **Observability & Trace Logs:** Tracks all agent decisions and interactions for audit purposes.
## Add-ons
- **User Accounts:** Sign up / login system with password hashing.
- **Multilingual Support:** Chat supports multiple languages using i18next.
- **Voice Input & Output:** Conversational interface supports speech recognition and text-to-speech.
- **Proactive Refill Alerts:** Users get notifications automatically before they run out of medicine.
- **CSV Input:** Medicine and order history loaded from provided CSV files.
